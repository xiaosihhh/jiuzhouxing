# 第十一届华为 ICT 大赛创新赛行动清单

更新时间：2026-11-13

## 参赛定位

- 赛事：第十一届华为 ICT 大赛创新赛
- 赛题：赛题一“基于华为云产品打造 AI 创新应用”
- 参赛对象：高等教育院校在校学生
- 队伍结构：3 名学生 + 1 名指导教师，须来自同一所高校
- 报名截止：2026-11-30
- 初赛：2026 年 12 月线上提交材料
- 中国总决赛：2027 年 3 月，材料提交与演示答辩
- 全球总决赛：2027 年 5 月，深圳线下答辩

> 时间与材料要求来自华为赛事页面及公开赛题说明。提交前仍须在报名后台核对最终版本。

## 官方与参考入口

- 华为 ICT 大赛 2026—2027 报名入口：<https://e.huawei.com/cn/talent/ict-academy/#/ict-contest?compId=85132004>
- 华为 ICT 大赛全球总决赛页面：<https://www.huawei.com/minisite/ict-competition-2025-2026-global/cn/index.html>
- 赛题一公开说明：<https://www.10100.com/article/152896034>

## 硬性要求

1. 使用华为云码道 CodeArts 代码智能体参与开发，并保留使用记录。
2. 基于智能体与 Skills 实现核心能力。
3. 关联 RDS、Redis 等华为云服务。
4. 完成华为云部署，提交可在线运行的作品。
5. 入围中国区总决赛及全球总决赛后，将源码开源到 Gitee 或 GitHub。
6. 提交完整源码、依赖、环境变量模板、部署指导、使用文档、演示截图或视频，以及明确的开源许可证。

## 优先级 P0：报名截止前

- 在华为赛事后台完成队伍报名，确认赛题一、学校、成员与指导教师。
- 完成 RDS for MySQL 实例并迁移当前本地数据结构。
- 完成 DCS for Redis 实例并替换内存缓存。
- 将系统部署到华为云 ECS/CCE，配置 HTTPS 公网域名。
- 设置稳定的 `AUTH_SESSION_SECRET`，关闭演示验证码并接入短信或在提交材料中明确演示边界。
- 保存 AgentArts、OBS、RDS、DCS、ECS/CCE 的控制台截屏和调用记录。

## 优先级 P1：初赛材料

- 5–8 分钟演示视频：痛点、完整操作、华为云架构、技术亮点、实际效果。
- 8–12 页答辩材料：创新点、用户价值、技术架构、华为云产品关联、数据与安全。
- 架构图、数据流图、Skills 调用链和部署截图。
- 30–50 名用户试用记录、典型反馈、改进前后指标。
- 仓库 README、部署说明、环境变量模板、许可证和可复现启动命令。

## 晋级后

- 将仓库公开到 GitHub/Gitee，确认许可证和第三方素材授权。
- 补充完整答辩稿、现场演示备份视频和离线降级方案。
- 准备 3 分钟、8 分钟和 15 分钟三种演示时长。

## 当前不建议虚构的内容

- 不得伪造 RDS/DCS 已接入状态。
- 不得伪造真实用户数量、评价或使用数据。
- 不得将本地演示地址描述为华为云公网部署。
- 不得在截图或仓库中出现 AK/SK、API Key、账号密码或个人手机号。
