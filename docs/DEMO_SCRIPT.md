# 九州行比赛演示脚本

建议录制时长：6–8 分钟

## 1. 开场与痛点（40 秒）

国内旅行信息分散在攻略、地图、酒店和交通平台之间，用户需要反复切换，预算、路线和预订信息难以形成闭环。九州行将这些步骤整合为一个中国旅行规划工作台。

展示首页与一句话定位，不要逐项念导航。

## 2. 华为云能力（50 秒）

展示架构与健康检查：

- AgentArts Managed Agent 负责出行方案生成。
- AgentArts Skill 执行目的地筛选与预算规划。
- MaaS 提供模型能力。
- OBS 保存社区视频与图片。
- RDS 和 DCS 在部署完成后展示数据库与缓存状态。

现场可访问 `/api/health`，展示 `agent=agentarts-managed`、`objectStorage=obs`。

## 3. 完整用户流程（3 分钟）

1. 在首页输入“预算 5000，亲子旅行 3 天，想看自然风景”。
2. 展示助手回答、技能标签和推荐卡片。
3. 选择北海，打开景点介绍。
4. 将目的地加入行程单并生成路线。
5. 在路线页添加途经城市，切换高铁或飞机。
6. 跳转携程酒店查询或 12306。

重点展示不同问题会产生不同回答，不展示时间过长的模型等待。

## 4. 社区与 OBS（1 分钟）

打开热门城市分享，播放 OBS 视频，展示点赞、收藏、评论和我的记录。说明视频通过私有桶签名 URL 访问。

## 5. 安全与工程化（50 秒）

- 手机号登录、scrypt 密码哈希与 HttpOnly 会话。
- 后端保存云端密钥，前端不暴露 AK/SK。
- 本地 JSON 自动降级，便于演示环境稳定运行。
- GitHub 仓库包含 README、部署说明、许可证和环境变量模板。

## 6. 结果与展望（40 秒）

总结已覆盖的 90 座城市、343 个景点、路线与预订闭环。下一步接入真实天气、实时房价、短信验证码与更多用户试点数据。

## 录制检查

- 隐藏终端、密钥、个人账号和真实手机号。
- 所有价格标记为参考值，预订链接使用官方平台。
- 准备一段录屏作为现场网络异常时的备份。
